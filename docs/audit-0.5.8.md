# 0.5.8 代码审查与整理

审查日期：2026-11-10。范围为当前插件源码、有效测试和本项目构建暂存目录。

## 修复的问题

- 模型设置测试也被强制要求持久会话 ID：新增仅限无历史的临时预约，受请求并发上限约束，不写入来源绑定。非法或相互冲突的 ID 不能降级绕过准入。
- HTTP 200 中的错误对象或无效 JSON 可能被记为成功：生成和压缩共用响应校验，保留明确错误分类及原重试边界。
- 非流式请求取消未关联预约上下文：生命周期完成可取消等待；生成读取使用可取消的上游关闭回调，同一连接只关闭一次。
- 完成事件交付后发生取消可能改变统计状态：已完成结果保持完成，不误记为取消。
- 输出后的上游错误帧和错误码可能回显运行密钥：统一脱敏后发送终止错误，不重新执行已输出的请求。
- 宿主回调长度转 C 整数前缺少边界：补充最大缓冲区检查。

## 结构与兼容性

身份解析、父子关系、准入、调度、执行生命周期、HTTP 传输、JSON 校验、SSE 帧解析分别维护。移除未使用的 PreferredAuth 和旧每会话配置结构字段，保留旧并发值迁移、跨版本文件格式、第三方 SDK 类型及许可。

没有合并不同会话的历史，也没有改变 API Key、模型或 prompt_cache_key 的业务含义。Key 粘性、子会话继承、并发队列、错误恢复和管理界面继续由回归测试覆盖。

## 验证与边界

Windows/Linux 竞态测试、静态检查、隔离 CPA 完整集成、前端与 Python 检查通过。历史审计只检查可达 Git 对象与启发式秘密特征，不能证明任意格式秘密均不存在；自动回归使用模拟上游，未据此宣称真实 AR 容量或缓存命中改善。

本地清理在新版验收后执行，仅针对本项目生成副本、旧安装包和重复临时测试。当前源码与有效回归测试保留；保留一份上一版二进制用于在途升级回归。具体删除范围和结果保存在本地 build/current/cleanup-result.json。
